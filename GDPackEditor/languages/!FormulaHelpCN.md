# 公式使用说明

## 变量

- `u` = 上一项的值（第一项取基准值）
- `n` = 当前序号（从 1 开始）
- 递推使用精确值：下一项以上一项公式的原始计算结果为起点（与 Excel 相同）；要整数请在公式里取整

## 运算符

- `+ - * /`：四则运算
- `%`：取余（做周期 / 分组）
- `**` 或 `^`：幂（两者等价），如 `u**2`
- `>` `<` `>=` `<=` `==` `!=`：比较（配合 if）
- `( )`：括号
- `-`：一元负号（负指数请自行加括号，如 `u**(-2)`）

## 可用函数（大小写不敏感，推荐小写）

- `abs(x)`：绝对值。例：`abs(u - 5)`
- `floor(x)`：向下取整。例：`floor(7 / 4)` = 1
- `ceiling(x)`：向上取整。例：`ceiling(1.2)` = 2
- `truncate(x)`：向零截断。例：`truncate(-1.5)` = -1
- `round(x)`：四舍五入到整数。例：`round(u * 1.06)`
- `round(x, d)`：四舍五入保留 d 位小数。例：`round(1.65, 1)` = 1.7
- `min(a, b)`：取较小（封顶）。例：`min(u * 1.06, 100)`
- `max(a, b)`：取较大（保底）。例：`max(u - 1, 0)`
- `if(条件, 真值, 假值)`：二分支。例：`if(n <= 10, u + 1, u + 5)`
- `ifs(条件1, 值1, 条件2, 值2, ..., 默认值)`：多分支。例：`ifs(n <= 4, 1, n <= 8, 2, 3)`
- `sqrt(x)`：平方根。例：`u + sqrt(n)`
- `exp(x)`：e 的 x 次方
- `log(x, 底)`：对数。例：`log(100, 10)` = 2
- `pow(x, y)`：x 的 y 次方（等价 `**`）

## 常用配方

- 等量累加（每项 +5）：`u + 5`
- 等量递减（每项 -5）：`u - 5`
- 比例成长（每项 ×1.06）：`u * 1.06`
- 比例衰减（每项 ×0.9）：`u * 0.9`
- 每N进1（每 4 项进 1）：`1 + floor((n - 1) / 4)` → 1,1,1,1,2,2,2,2...
- 递增封顶（每项 +5，封顶 100）：`min(u + 5, 100)`
- 递减保底（每项 -1，不低于 0）：`max(u - 1, 0)`
- 条件（前 10 项每项 +1，之后每项 +5）：`if(n <= 10, u + 1, u + 5)`
- 逐项加平方（每项 +n²）：`u + n**2`
- 去0周期循环（1~5 循环、不出现 0）：`(n - 1) % 5 + 1`
- 上下限限制（每项 +2，限制在 10~100）：`min(max(u + 2, 10), 100)`
- 指数爆炸增长（从 100 起每项 ×1.5，用序号直接算）：`100 * 1.5 ^ (n - 1)`

## 重要提示

- **整数复利请用闭式写法**（直接用 n 算第 n 项）：`round(1 * 1.06 ^ (n - 1))`。
  不要写 `round(u * 1.06)`——精确递推下它会在起点卡住不动（1 → 1.06 → 取整 1 → ...）。
- 补位（左侧补 0）作用于**数值段**，在插值之前执行：分割段 `1` 先补成 `01`，再插值成 `01a`。
- 除零、负数开小数次方等无实数解的行以 ! 标记并跳过；公式不合法时提示「公式无效」。
- 所有结果最多保留 6 位小数。
